## What's new (2026-09-24 to 2026-11-22)

Four items, each opened today. None of them changes a grade; they are logged so the next pass has dated leads.

1. **Anthropic, model-specific prompting guide (vendor documentation; dated 2026-11-09 by the release notes).** [Prompting Claude Fable 5.2](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-fable-5-2). The guide page prints no date; the [release notes](https://platform.claude.com/docs/en/release-notes/overview) entry headed "November 9, 2026" announces the model and links the guide "For model-specific prompting patterns". Relevant to the `chain-of-thought` row's scope note on thinking controls: "the effort level sets how much the model thinks, how many tool calls it makes, how long a turn takes, and how many tokens it uses", and "In Anthropic’s testing, an instruction to answer directly without deliberating didn’t stop the model from thinking at `medium` and above." **What it does not show:** every figure on the page is the vendor's own testing ("In Anthropic’s testing…"), with no dataset, task list or sample size published on the page; it is guidance for one model family, not a measured comparison, and nothing in it is reproducible from the page alone.
2. **Google, Gemini API release notes, entry "November 18, 2026" (vendor changelog).** [Gemini API changelog, Markdown rendering](https://ai.google.dev/gemini-api/docs/changelog.md.txt) — this URL redirected today to `aistudio.google.com/docs/changelog.md`, which is the text that was read; the HTML rendering of the changelog was not opened. The entry: "**Gemini 4 Neon (`gemini-4-neon`) generally available (GA)**" and, of the same model, that it "supports four" thinking levels "(`low`, `medium`, default `high`, and `xhigh`)". **What it does not show:** it is an availability and pricing announcement; it contains no prompting guidance and no statement about chain-of-thought prompting. Whether Google's Gemini 3 advice (use the thinking level instead of prompting for step-by-step reasoning) is repeated for this model was not checked — the linked "What's new in Gemini 4 Neon" page was not opened.
3. **OpenAI, API changelog, entry "Nov 17" under November 2026 (vendor changelog).** [OpenAI API changelog](https://developers.openai.com/api/docs/changelog). The entry: "Use GPT-6.2 Astra for demanding reasoning and coding tasks, or GPT-6.2 Sol for everyday coding and agent workflows." and "GPT-6.2 changes how the Responses API preserves reasoning when you edit a conversation’s prefix and how it handles the top-level instructions field. See the GPT-6.2 migration guide for details". An earlier entry, "Oct 26", says of GPT-6.1 Terra: "See the GPT-6 guide for prompting and migration guidance." **What it does not show:** neither entry states any prompting advice itself; the migration guide and the GPT-6 guide they point to were not opened, so nothing about their content is claimed here.
4. **Chen, "Simplicity Goes Far: Auditing Prompt Optimizers with Demonstration-Conditioned Prompt Search" — preprint, not peer-reviewed.** [arXiv:2611.22605](https://arxiv.org/abs/2611.22605), v1 submitted "Tue, 17 Nov 2026"; the comments field reads "13 pages, 2 figures, 4 tables" and names no venue. Abstract only was read. It reports that a generate-and-select control with "no learned update, reflection, or evolution" replaces PPO in StablePrompt "matching classification accuracy within 0.5 pp at roughly one-third the measured cost", and in DSPy-based systems "matches GEPA's macro accuracy on GPT-4.1-mini while using 55% fewer rollouts at 32% lower measured API cost on average"; it also says "additional mechanisms retain advantages in some open-ended and reasoning-heavy settings". Adjacent to the `take-a-deep-breath` row, whose source (OPRO) is an automatic prompt optimizer. **What it does not show:** a single-author preprint read at abstract level — the tasks, the number of runs and the variance were not examined; the GEPA comparison is on one model and "under the reported budgets"; OPRO is not named in the abstract, so no claim about OPRO follows from it.
