# Templates

Copy-paste starting points for contributions. Using them keeps every entry
consistent and makes the CI checks (and the human review) pass on the first try.

- [`technique-entry.template.yml`](technique-entry.template.yml) — a blank entry
  for [`../data/techniques.yml`](../data/techniques.yml). Fill **every** field.

**Hard rule** (see [`../CONTRIBUTING.md`](../CONTRIBUTING.md)): a technique with no
grade and no primary source does not get merged. The template exists so you never
forget either one.
