# Updates

Prompt engineering moves weekly — models ship, numbers drift, new evidence lands. To stay honest this repo publishes a dated log.

- One entry per ISO week (e.g. `2026-W35.md`) covering: **grades changed**, **techniques/folklore added**, **numbers re-verified**, and **sources added**.
- Every grade change names the evidence that moved it. Nothing changes silently.
- Weeks with no material change still get a short "no material change" note, so the record is continuous.

This cadence is not optional decoration — it's what separates an evidence ledger from a snapshot that rots into "guide #4001". A grade with a stale `last_verified` is a bug.
